# 结构模型估计数值例子

两个脚本都使用 Python 3.10 或更新版本及标准库。先运行二元例子，再运行多项例子。

## 二元购买决策

脚本对应[第 3 单元](../notes/03-binary-choice-example.md)，使用 Python 3.10 或更新版本，仅依赖标准库。所有样本为模拟数据，不访问网络、不读取私人数据、不写出数据文件。

在仓库根目录运行：

```bash
python code/binary_choice_demo.py
python code/binary_choice_demo.py --seed 20261013 --n-per-price 4000
```

## 输出内容

1. **观测等价**：两组参数在价格 10 处购买概率相同，在价格 15 处不同。
2. **总体识别**：用价格 10、15 的理论购买率准确恢复 $a=2,b=0.1$。
3. **有限样本估计**：随机生成两个价格组的独立购买结果，再求闭式最大似然估计、拟合概率和价格系数标准误。
4. **信息强度**：用理论概率比较价格组为 10 与 15、10 与 10.1 时的渐近标准误。

第 3 项利用“两种价格、两个系数”的特殊结构，不需要数值优化器。脚本先估计不受符号约束的系数；若抽样结果给出非正的 $b$，会说明它不符合教学设定。不要将这个闭式公式直接用于多价格组或其他需求模型。

## 内置核对与边界

脚本检查观测等价、两个总体购买率的参数恢复、拟合率与样本率相等、估计参数的似然不低于模拟真值，以及本例中窄价格差导致的精度下降。这些是对数学关系和实现的核对，不是对真实消费者行为的验证。

每个价格组必须同时包含购买者与不购买者，否则 logit 转换没有有限值，脚本会明确终止而不截断购买率。小样本可能触发这个边界；默认样本量用于稳定演示。标准误采用独立组的大样本 Delta 近似，不是任意样本下的精确区间。

修改随机种子观察抽样差异，修改每组样本量观察精度变化。若修改源代码中的价格或真值，还应检查数据是否仍符合识别条件。

## 两种产品与外部选项

[multinomial_logit_demo.py](multinomial_logit_demo.py) 对应[第 5 单元](../notes/05-multinomial-logit.md)和[第 6 单元](../notes/06-elasticities-and-iia.md)。运行：

```bash
python code/multinomial_logit_demo.py
python code/multinomial_logit_demo.py --seed 20261015 --n-per-market 4000
```

脚本设定六组外生价格，每组包含不购买、A、B 三种互斥选择，依次完成：

1. 用理论份额构造总体目标，恢复已知参数 $c_A=2,c_B=1.6,\alpha=0.1$。
2. 生成独立模拟选择，以分组多项似然估计三个共同参数。
3. 从信息矩阵计算价格系数的大样本标准误。
4. 用估计参数计算价格弹性，并预测 A 价格从 10 变为 12、B 价格保持 12 时的需求份额。
5. 展示 IIA 与把重复标签误当作独立新选项的后果。

### 算法和单位

`fit` 使用带回溯步长的牛顿法；`objective` 返回按消费者总数平均的对数似然、梯度和负 Hessian。协方差计算将平均信息矩阵乘回总样本量。为改善数值尺度，内部价格除以 10，内部价格系数为 $10\alpha$，输出系数和标准误时再除以 10。

默认种子下得到 $\hat c_A=2.067294$、$\hat c_B=1.661578$、$\hat\alpha=0.108087$，价格系数标准误约为 0.004888。这些是模拟输出，不能解释为实证估计。

### 数学核对和适用范围

内置检查包括：概率相加为 1；份额对数比恢复系统效用；总体参数恢复；解析价格导数与有限差分一致；价格变动时份额变化相加为零；IIA 概率比限制；样本估计似然不低于真值处的样本似然。

脚本保守地要求每个模拟市场的每个选项人数均为正；否则停止并报告问题。这只是教学实现的范围限制，一般多项 Logit 中某个单元格为零，并不必然意味着不存在有限最大似然解。奇异信息矩阵或迭代不收敛也会明确报错。

估计不施加价格系数符号约束；若估计的 $\alpha\le0$，输出会提示它不符合教学设定。模型未加入共同市场冲击、内生价格、随机系数或企业供给，因此当前标准误与反事实应按这些条件解释。
