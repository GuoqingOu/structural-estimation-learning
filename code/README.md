# 二元购买决策数值例子

脚本对应[第 3 单元](../notes/03-binary-choice-example.md)，使用 Python 3.10 或更新版本，仅依赖标准库。所有样本为模拟数据，不访问网络、不读取私人数据、不写出数据文件。

在仓库根目录运行：

```bash
python code/binary_choice_demo.py
python code/binary_choice_demo.py --seed 20261013 --n-per-price 4000
```

## 输出内容

1. **观测等价**：两组参数在价格 10 处购买概率相同，在价格 15 处不同。
2. **总体识别**：用价格 10、15 的理论购买率准确恢复 $a=2,b=0.1$。
3. **有限样本估计**：随机生成两个价格组的独立购买结果，再求闭式最大似然估计、拟合概率和价格系数标准误。
4. **信息强度**：用理论概率比较价格组为 10 与 15、10 与 10.1 时的渐近标准误。

第 3 项利用“两种价格、两个系数”的特殊结构，不需要数值优化器。脚本先估计不受符号约束的系数；若抽样结果给出非正的 $b$，会说明它不符合教学设定。不要将这个闭式公式直接用于多价格组或其他需求模型。

## 内置核对与边界

脚本检查观测等价、两个总体购买率的参数恢复、拟合率与样本率相等、估计参数的似然不低于模拟真值，以及本例中窄价格差导致的精度下降。这些是对数学关系和实现的核对，不是对真实消费者行为的验证。

每个价格组必须同时包含购买者与不购买者，否则 logit 转换没有有限值，脚本会明确终止而不截断购买率。小样本可能触发这个边界；默认样本量用于稳定演示。标准误采用独立组的大样本 Delta 近似，不是任意样本下的精确区间。

修改随机种子观察抽样差异，修改每组样本量观察精度变化。若修改源代码中的价格或真值，还应检查数据是否仍符合识别条件。
